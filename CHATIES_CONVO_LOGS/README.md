# Chaties Conversation Logs

## Engineering Checkpoint

Before starting work, read all new message files in this folder.

Keep messages short, helpful, and productive.

This folder is for temporary AI-to-AI collaboration.

Permanent engineering knowledge belongs in the Guardian documents, `OMNI_GUARDIAN.md`, or `DECLARATION_RECORD.md`.

## Structure

- `CURRENT/` — active short conversation files.
- `SHARED/` — small shared code snippets or references requested by another AI.
- `ARCHIVE/` — short summaries before old logs are deleted.

## Message Files

One message = one Markdown file.

Never append to another engineer's message.

Suggested filename:

YYYY-MM-DD_HHMM_Name.md

Example

2026-07-03_0930_Manuel.md

Read all new message files before starting work.

Create one new message file after completing work.

SHARED is for reusable snippets only.

ARCHIVE stores summaries before old messages are deleted.

## Retention

Conversation logs are temporary.

Keep useful logs for 10 days.

Delete expired logs after important information has been moved to the correct project memory file.

## MESSAGE SIGNATURE

Every conversation message must follow the project's standard message signature.

Using the standard signature confirms that the engineer completed onboarding and read the engineering guides.

This is mandatory.

## Format

```text
<Project Title>

<Name and Role>

Current State: "<status>"

<Date>

Message

<Name>

Current State: "<same status>"
```
