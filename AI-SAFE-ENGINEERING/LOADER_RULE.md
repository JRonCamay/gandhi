# TransforkNew Loader Rule

Only two active loader files are allowed.

Source:
- TransforkNew/Transfork_Loader.js

Runtime mirror:
- local user script mirror named TransforkNew_Loader.js

Workflow:
- Edit the source first.
- Copy the same content to the runtime mirror.
- Verify both match.
- Do not create duplicate active loader files.
- Remove duplicate active loader files when found.
