# 🛡 Guardian Standards

The Guardian Standards are the project's engineering operating system.

They provide:

- Consistent engineering decisions.
- Runtime ownership.
- Project memory.
- Reusable knowledge.
- AI collaboration.
- Safe long-term maintenance.

Trust the Guardians.

Do not recreate systems that the Guardians already solve.

---

# 🤝 AI Collaboration

AI engineers collaborate through repository memory.

Before starting work:

- Read the latest project guides.
- Read the latest conversation logs when applicable.
- Search project memory before creating new reusable systems.

After completing work:

- Update the required project memory.
- Leave a short message for the next engineer when appropriate.

---

# 📂 Project Memory

Project memory is maintained by AI engineers.

Important files include:

- `OMNI_GUARDIAN.md`
- `DECLARATION_RECORD.md`
- `CHATIES_CONVO_LOGS/`

Updating project memory is part of implementation.

A task is not complete until both the implementation and project memory are synchronized.
